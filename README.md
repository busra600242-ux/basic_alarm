# ⏰ Python Alarm

Python ile oluşturulmuş basit bir alarm uygulaması.

## Özellikler

* Alarm saati belirleme
* Alarmı doğrulama
* Belirlenen saatte alarm verme
* Çıkış seçeneği

## Çalıştırma

Terminalde proje klasörüne girip:

```bash
python main.py
```

komutunu çalıştırın.

## Gereksinimler

* Python 3.x
* `datetime` modülü
* `time` modülü
